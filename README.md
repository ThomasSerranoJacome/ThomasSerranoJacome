## Ruta de aprendizaje

Mi formación avanza desde los fundamentos de programación hacia el desarrollo backend:

**Python → Java → SQL y bases de datos → JavaScript → Automatización → Backend**

| Área | Dónde estoy ahora |
| :--- | :--- |
| **Python** | Usado en proyectos académicos y prácticos |
| **Java** | Estudio progresivo: fundamentos, control de flujo, strings, POO (encapsulamiento, herencia, polimorfismo, interfaces, clases abstractas), arreglos, listas, genéricos y relaciones entre clases |
| **SQL y bases de datos** | Trabajo con MySQL y PostgreSQL mediante DBeaver en proyectos académicos |
| **JavaScript** | Aprendiendo lo básico |
| **Automatización** | Explorando flujos en n8n, webhooks, APIs y bases de datos |
| **Backend y APIs** | Construyendo fundamentos; siguiente paso después de los temas anteriores |
| **Docker** | Etapa inicial |
